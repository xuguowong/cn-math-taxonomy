连接自部署模型

在项目根目录的 .env 配置 OpenAI 兼容接口，然后运行 npm start。图片需要视觉模型，并设置 MATH_AI_VISION=1。

MATH_AI_BASE_URL=http://127.0.0.1:8000/v1
MATH_AI_MODEL=你的模型名
MATH_AI_API_KEY=
MATH_AI_VISION=1

API Key 只在服务端使用。详细步骤见仓库的 analyze/README.md。

AI 模式会将题目和图片发送至你配置的模型服务。本地检索不会发送题目。
