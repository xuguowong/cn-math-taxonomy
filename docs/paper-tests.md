# 打印纸质测试

纸质测试直接使用现有题库，不需要连接 AI 模型服务。支持浏览器打印或另存为 PDF。

## 入口

- **正在答题**：题目顶部点击「打印纸质测试」。
- **还没有开始答题**：在「按年级整体诊断」中选好年级和上 / 下册，点击「打印本范围试卷」。
- **查看已完成的结果**：原有「打印 / 另存为 PDF」打印的是诊断报告，和纸质试卷是两个功能。

## 生成与打印

1. 选择范围：本次诊断目标范围、当前知识点，或只打印当前这一题。后两项仅在已开始答题时提供。年级 / 册次 / 章节使用已选范围，单知识点诊断使用目标知识点，不额外混入范围外的先修题。
2. 设置题数（1–60），默认使用当前诊断题量上限。题库不足时显示实际题数，不重复凑题。
3. 选择答题留白：紧凑、适中或充足。需要列式、画图时可选择充足。
4. 默认不选拓展题，需要时勾选「包含拓展题」。
5. 默认不附答案。勾选「附参考答案（另起一页）」后，学生题目后会新增家长用的答案与解析。
6. 点击「打印 / 另存为 PDF」，在浏览器窗口选择打印机或「另存为 PDF」。纸张使用 A4，可关闭浏览器页眉页脚。

试卷包含姓名、日期空栏和答题区域；选择题保留选项和图示。图形保留原题颜色，涉及颜色的题目应使用彩色打印。答案与解析来自题库，仍需家长核对。

「重新选题」可以更换组合；切换留白或是否附答案时，同一组合保持不变。当前题在范围与难度允许时排在第一题。其余题目按章节轮流抽取，优先覆盖不同知识点，再补充同一知识点的后续题。

## 与线上诊断的区别

纸质试卷是固定题目，不会根据作答动态追问、补基础或回溯先修。范围大而题量有限时，只覆盖部分知识点，预览会显示实际覆盖数量。

打印不会提交当前答案，也不会改变线上会话、草稿、出题记录或孩子的诊断历史。纸面作答不会自动录入网站或生成诊断报告。关闭预览后可以继续原来的线上答题。

## 实现与验证

| 文件 | 用途 |
| --- | --- |
| `diagnose/paper.js` | 固定抽题、试卷 HTML、预览和打印调用 |
| `diagnose/paper.css` | 打印预览窗口样式 |
| `diagnose/app.js` | 答题页和年级诊断的打印入口 |

试卷在独立 iframe 中排版和打印，避免把导航、按钮、在线反馈或草稿印到卷上。学生卷和答案页分开生成，默认不生成答案页。静态资源包含在离线缓存中。

```bash
npm run test:paper
python3 scripts/test-paper-browser.py
```

浏览器测试需要 Python Playwright、pypdf 和 Chrome，可通过 `--chrome` 指定路径。测试实际生成 A4 PDF，检查答案分页、学生卷不含答案、打印调用、图形题、手机预览，以及在线草稿 / 会话保持不变。默认 PDF 和截图输出在 `/tmp/cnm-paper-browser`。
